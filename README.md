# Будильник с задачами

Простое мобильное приложение на Python + Kivy.

## Что умеет

- показывает текущее время;
- добавляет будильник в формате `ЧЧ:ММ`;
- к каждому будильнику можно добавить задачу;
- будильники сохраняются в `alarms.json` внутри пользовательской папки приложения;
- будильник срабатывает, когда приложение открыто;
- при срабатывании играет звук и появляется окно с задачей;
- можно включать/выключать и удалять будильники.

## Важно

Это первая простая версия. Она проверяет будильники через Kivy `Clock`, поэтому надёжно работает, когда приложение открыто.

Для настоящего Android-будильника, который срабатывает при закрытом приложении и заблокированном экране, нужно делать отдельную Android-логику через AlarmManager/foreground service. Это уже следующий уровень проекта.

## Запуск на Windows в PyCharm

1. Открой папку проекта в PyCharm.
2. Создай виртуальное окружение `.venv`.
3. Установи зависимости:

```bash
pip install -r requirements.txt
```

4. Запусти:

```bash
python main.py
```

## Сборка APK через Buildozer

Buildozer обычно запускают на Linux, macOS или Windows через WSL.

```bash
pip install buildozer
buildozer android debug
```

Готовый APK появится в папке `bin/`.
